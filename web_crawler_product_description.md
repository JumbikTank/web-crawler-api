# Краулер заданных URL — границы проекта

## Идея приложения

Пользователь передаёт список публичных HTTP(S)-адресов. Сервер проверяет robots.txt,
скачивает разрешённые HTML-страницы, сохраняет результаты и позволяет получить
HTML, извлечённый текст и метаданные. В ответе на запуск есть результат каждого адреса.

Обрабатывается только переданный список. Ссылки внутри страниц не добавляются
в обход, поэтому поведение и объём работы предсказуемы для учебной демонстрации.
Точные 10 функциональных и 10 нефункциональных требований находятся в [README](README.md).

## Что взято из примера большого краулера

Источник: [схема Internet Crawler](https://jumbiktank.github.io/internet-crawler/internet_crawler.svg).
Она использована как пример архитектуры, а не обязательство реализовать обход всего интернета.

| Элемент схемы | Учебная реализация |
|---|---|
| Загрузка списка seed URLs | `POST /crawl` принимает список из 1–20 адресов. |
| Downloader и robots.txt | aiohttp скачивает страницы, Protego проверяет правила; действуют таймауты и интервалы запросов. |
| Сохранение `rawHTML` | HTML хранится в SQLite или S3, читается через `GET /html`. |
| Каталог `url_data` | Сохраняются URL, ссылка на HTML, SHA-256 и время; SQLite либо DynamoDB. |
| Дедупликация по `content_hash` | Одинаковое содержимое имеет один ключ хранения; доступен поиск URL по хешу. |
| HTML processor → текст | selectolax с нативным C-движком Lexbor извлекает текст по `GET /text` из сохранённого HTML. |
| Кеширование | DNS-кеш HTTP-клиента и ограниченный кеш robots.txt. |

## Что не входит в ДЗ

Рекурсивное обнаружение новых URL, Kafka/SQS, распределение доменов между машинами,
Flink checkpoints, распределённые кеши, GSI DynamoDB, Spark/EMR и обход миллиардов страниц
относятся к примеру большой системы. Они не входят в требования текущего приложения.

Числа «5 млрд URL за неделю», «10–30 тыс. страниц в секунду» и «три сервера» из схемы
не используются как показатели или обещания учебного сервера.
Оценка «1 МБ на страницу» послужила ориентиром для отдельного ограничения:
максимум 1 МиБ HTML в UTF-8. Это лимит API, а не утверждение о среднем размере интернета.

## Границы обработки

- Для доступа к заданной странице сервер может запросить robots.txt и следовать HTTP-перенаправлениям.
- Другие ссылки, изображения, стили и скрипты со страницы не скачиваются.
- HTML разбирается как документ без браузера, выполнения JavaScript и вычисления CSS.
- HTML сохраняется постоянно; текст получается из сохранённого документа при чтении.
- Выполнение пакета происходит внутри HTTP-запроса, без фоновой очереди.
- Клиентская часть относится к следующей части ДЗ.
